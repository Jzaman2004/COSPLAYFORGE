## 📝 Placeholder System

All demo assets have **SVG placeholders** that:
- Load instantly (no server requests)
- Display professionally
- Can be replaced with real assets anytime
- Don't affect the user experience

Just drop real files into these folders and they'll auto-load!

## 💾 File Size Recommendations

- **Videos**: H.264 MP4, <10MB per file (1080p, 15-30s)
- **Images**: PNG transparent, <5MB (1024px+)
- **Audio**: MP3 128kbps, <500KB (3-5s clips)
- **SVG**: Keep <100KB (inline)
